# AWG Review: Changes

- **Nov 27, 2026** — The Work Request Journey (resources.mismo.org/mms/journey/) now shows this page itself, in tour mode, for the AWG steps: opened inside the journey with ?tour=1 it uses the journey's practice files, saves nothing and sends nothing. The software checks now accept MISMO Link's format (the MMS's MISMO Link check): container names in plain words (Escrow Detail) as well as ESCROW_DETAIL, and data point rows without an XPATH; it flagged every name a facilitator had fixed for MISMO Link. A documentation submission shows as Documentation on the agenda, not three zeros.
- **Nov 26, 2026** — Masthead matches the other MISMO tools (CN-053): the same bar, logo box, divider and name as Certification Management, so the MISMO logo sits in the same spot in every tool (68px bar; Certification Management's 62px bar on a phone). The left menu starts right under it, and jumping to the submission's toolbar stops just below it. The old December hat is gone; the shared holiday file does December now.
- **Nov 25, 2026** — The agenda ring counts submissions with no draft yet, so it is never an empty circle. A submission moved on by hand in the MMS now leaves the agenda (WR2025_23 had stayed on it after moving to License Designation).
- **Nov 25, 2026** — Browser Back button (CN-033): each page and each submission already has its own address, so Back already returns to the last page or submission you were on; it never undoes a vote or decision. Help now says so. The shared back.js is deliberately not loaded (it would make Back need two presses), and AWG Review has no right-hand panels or drawers for Back to close.
- **Nov 25, 2026** — Browser tab icon now matches mismo.org (CN-030): the one shared icon at resources.mismo.org/assets/favicon-48x48.png (the page had no icon line before).
