# MISMO Media's old web address

MISMO Media moved from resources.mismo.org/marketing-hq/ to resources.mismo.org/media/ (Jonna, Nov 22, 2026).
This folder keeps the old address working once the marketing-hq repository is renamed to media:

- `index.html` sends anyone with the old bookmark to /media/, keeping the rest of the address (the part after #).
- `mm-headers/`, `email/`, `hl-bridge/` and `matters/` are exact copies of the files already sent in emails or loaded by the website,
  so pictures in sent MISMO Matters editions and on mismo.org keep showing. New files go in the media repository.

While the marketing-hq repository still exists, GitHub serves that instead of this folder. Owned by MISMO Media.
